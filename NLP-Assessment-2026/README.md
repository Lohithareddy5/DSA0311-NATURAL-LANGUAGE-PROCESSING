# NLP-Assessment-2026

Internal assessment folder structure for **DSA0311 - Natural Language Processing**.

## Contents

- **`Unit-1`** to **`Unit-5`**: Units 1 through 5, each containing `Assessment-1`, `Assessment-2`, and `Assessment-3`
- **`Capstone Project`**: Contains `PPT`, `Reports`, `Datasets`, and `Source Code`
- **`Assignments`**: Contains `Assignment-1` through `Assignment-5`
- **`Certificates`**: Course and assessment certifications
- **`experiment`**: Practical / lab experiment implementations
